# data/ — raw and derived data

*Everything in this directory except this README is gitignored: bulk, refetchable, or subject
to the open Moody's terms-of-use question. This file documents what lives here, where each file
comes from, and which script consumes it.*

## moodys/ — the rating histories (the evaluation's answers)

| File | What / where from |
|---|---|
| `xbrl100-obligor-2026-08-11.zip` | Entity-level rating histories: 21,383 XML files (ROCR XBRL), one per obligor, all rating actions since June 2012. Source: Moody's SEC Rule 17g-7(b) disclosure page, ratings.moodys.com (Regulatory Affairs → 17g-7 rating histories; free account required). Downloaded by Robert on 2026-08-15; file date 2026-08-11; content ends August 2025 because the rule allows a 12-month embargo, which Moody's uses fully |
| `xbrl100-issuer-2026-08-11.zip` | Instrument-level histories: 73,687 XML files, one per issuer, each bond with CUSIP, coupon, maturity and its own action history. Same source and dates |
| `derived/moodys_corporates.json` | All 13,025 Corporate entities of both sets (name, OI, LEI). Generated by `evaluation/pipeline/build_queue.py` from the zips |

Consumed by `build_frame.py`, `compile_folders.py` (ratings.json extraction) and
`build_observations.py` indirectly through the folders. The zips stay local and are not
redistributed pending the terms-of-use question (docs/assumptions-review.md).

## edgar/ — SEC reference lists and caches

| File | What / where from |
|---|---|
| `company_tickers.json` | All ~8,000 currently listed companies with CIK and title. https://www.sec.gov/files/company_tickers.json, fetched 2026-08-29 |
| `cik-lookup-data.txt` | Every EDGAR registrant name ever, ~900k lines "NAME:CIK:". https://www.sec.gov/Archives/edgar/cik-lookup-data.txt, fetched 2026-08-29 |
| `sic_cache.json` | CIK → [SIC code, description], built from https://data.sec.gov/submissions/CIK##########.json by `build_frame.py` (matched entities) and `sic_sweep_listed.py` (all listed companies) |
| `sic_sweep_listed.done` | Marker that the listed-universe sweep completed, with counts |

## frame/ — the sample frame

| File | What |
|---|---|
| `retail_frame.json` | 186 Moody's Retail/Apparel entities with EDGAR match, SIC, scope decision, group, filing status and current rating. Generated by `evaluation/pipeline/build_frame.py` plus the reverse-pass additions documented in notes/rating-history-file.md |

## Regenerating

Everything here except the two Moody's zips (account download) and the decision files under
evaluation/ can be regenerated: `build_frame.py` → frame, `sic_sweep_listed.py` → cache,
`build_queue.py` → derived list. SEC fetches identify themselves per SEC fair-use policy and
stay under 10 requests/second.
