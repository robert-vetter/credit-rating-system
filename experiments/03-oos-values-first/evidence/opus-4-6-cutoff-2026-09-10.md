# Evidence snapshot — Claude Opus 4.6 cutoff and parameters

Retrieved 2026-09-10 from https://platform.claude.com/docs/en/models/opus-4-6/overview (also
verified 2026-08-31). Quoted verbatim from the page's "Capabilities" and "Availability" tables:

| Feature | Value |
|---|---|
| Model ID (Claude API) | `claude-opus-4-6` |
| Context window | 1M tokens |
| Max output | 128K tokens |
| Thinking | Adaptive (extended deprecated) |
| Default effort | `high` |
| **Reliable knowledge cutoff** | **May 2025** |
| **Training data cutoff** | **Aug 2025** |
| Status | Active (legacy) |
| Released | February 5, 2026 |
| Retirement | Not sooner than February 5, 2027 |
| Input / Output price | $5 / $25 per MTok; Batch API 50% discount |

Footnote on the page: "Reliable knowledge cutoff: the date through which the model's knowledge is
most extensive and reliable." The experiment's boundary uses the broader *training data* cutoff
(Aug 2025) plus a one-month buffer (B = 2025-09-30). Model IDs without a date suffix are pinned
snapshots per https://platform.claude.com/docs/en/about-claude/models/model-ids-and-versions.
The `model` field of every API response is stored with the results as run-time confirmation.
